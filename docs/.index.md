## (root) · NeoScore
- File: README.md
- Children: architecture, creative-lab, global-rules

Neo-partituras para que personas que no leen música puedan cantar en un coro: la letra es lo principal y debajo de cada sílaba una cuadrícula de colores muestra la melodía de su voz.
El siguiente paso es un asistente de entonación que hace sonar cada nota y compara en directo lo que cantas con la nota que toca.

## architecture · Arquitectura
- File: architecture.md

Cómo está construido NeoScore: una aplicación web estática que funciona entera en el navegador y se publica en GitHub Pages, sin servidor ni cuentas.
La página lee el MusicXML directamente (en JavaScript), lo dibuja como neo-partitura, hace sonar las notas con Tone.js y escucha con pitchy el micrófono para comparar lo cantado con la nota que toca.
